# Release staging status

This directory is a pre-publication staging copy for the manuscript repository.

Important:
- No third-party raw datasets are redistributed here.
- No pretrained model weights are included.
- No row-level prediction tables or participant identifiers are included in the public derived-data staging set.
- The copied analysis scripts preserve the scientific workflow, but portability review is still pending because some scripts contain local Windows absolute paths.
- Do not publish this directory to GitHub until the portability report has been reviewed and the release-validation step has passed.
