# Release status

This repository contains the public reproducibility code accompanying the manuscript.

Current release line: v1.0.1

Important:
- No third-party raw datasets are redistributed here.
- No pretrained model weights are included.
- No row-level prediction tables or participant/worker/subject identifiers are included.
- Public-release scripts use repository-relative paths and passed the release portability checks.
- Scientific parameters, feature definitions, participant splits, random seeds, outcomes, and reported results were not altered by the portability or metadata corrections.
- Versioned software releases are archived through the GitHub-Zenodo integration.
- Derived aggregate/fold-level results and reproducibility materials are handled in a separate Zenodo record.
