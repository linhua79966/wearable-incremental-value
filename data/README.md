# Data policy

This repository must not redistribute original third-party raw datasets unless redistribution rights have been explicitly verified.

Planned repository policy:
- Original Dataset A data: cite and obtain from the original source repository.
- Original Dataset B data: cite and obtain from the original source/publication.
- Original Dataset C data: cite and obtain from the original source repository.
- Do not commit pretrained model weights.
- Author-generated derived result tables, reproducibility records, manifests, and non-identifying aggregate outputs may be placed in the release package after final review.

The final Data Availability statement and exact source links/DOIs will be completed before v1.0.0 release.
