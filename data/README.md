# Data policy

This public repository contains analysis and reproducibility code. It does not redistribute original third-party raw datasets.

## Source datasets

- **Dataset A:** Obtain the original data from the source repository and cite the original publication.
- **Dataset B:** Obtain the original data from the source repository or publication and follow its access terms.
- **Dataset C:** Obtain the original data from the source repository and cite the original publication.

## Redistribution restrictions

The repository does not redistribute raw wearable recordings, participant/worker/subject identifiers, participant-level or row-level prediction tables, pretrained model weights, or derived embedding arrays. Original datasets and third-party materials remain subject to their respective licenses and access conditions.

## Public reproducibility archives

- **Analysis software (v1.0.1):** https://doi.org/10.5281/zenodo.22661192
- **Author-generated derived reproducibility materials (v1.0.0):** https://doi.org/10.5281/zenodo.22661607

The derived reproducibility archive contains aggregate and fold-level results, feature dictionaries, quality-control and convergence audit materials, manifests, and checksums. These materials do not replace the original source datasets.

Users should consult the manuscript's Data Availability Statement and the original data providers' terms when obtaining or reusing source datasets.
